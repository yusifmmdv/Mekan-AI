# Design system

Warm ivory #f7f5ef; charcoal #262a25; bronze #826343; muted olive #6a705f. Editorial Georgia headings plus system sans body (full Azerbaijani glyph support). Fine borders, roomy grids, rounded controls, large architectural photography. UI/UX skill architecture/minimalism search was relevant; marketplace/vibrant search was rejected as off brief. No fabricated social proof. 44px controls, visible focus, semantic labels, reduced motion, responsive 375–1440px layouts.

## Startup MVP direction

Hero → three-step value proposition → interactive on-photo shopping → home/office/studio audiences → single creation CTA. Preserve the warm interior-design palette and Azerbaijani-safe typography. UI/UX SaaS search matched Hero + Features + CTA; generic blue/glass palette was not adopted because the existing industry-specific system fits the product. No invented usage counts, partner badges, testimonials or results. Cards open over furniture and remain usable for purchase actions; keyboard chips and touch offer equivalent selection. Prepared examples are labelled separately from live results.
